# change provider ui improvement

## Intent

When "change provider" is clicked, we want essentially the same UI as when we create a brief. Currently, there is a textbox interface which allows the user to provide potentially invalid providers and models. We should have drop-downs and lists of valid models.

### Success criteria

When switching providers, the providers appear in a dropdown
valid models are presented in a UI that mimics that of the "create a feature brief" window
