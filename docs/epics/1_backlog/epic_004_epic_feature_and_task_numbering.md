# Epic, feature, and task numbering

## Intent

Currently, each epic, feature, and task is numbered canonically. I would instead want a heirarchical numbering - epic 3 is epic_3 or 003, whatever. Feature 3.2 is the second feature of epic 3. Task 3.2.4 is the fourth task of that feature.
